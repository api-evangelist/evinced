# Evinced

> Evinced is an AI-powered digital accessibility platform that automatically detects, clusters, tracks, and prevents accessibility (WCAG/ADA) issues across web and mobile applications. It ships developer-first automation SDKs and Model Context Protocol (MCP) servers so AI coding agents can analyze and remediate accessibility issues in-flow.

This file was generated by the API Evangelist enrichment pipeline from the Evinced APIs.json profile and public developer surface (method: generated). Evinced publishes no public REST API/OpenAPI; its developer surface is automation SDKs and MCP servers.

## Products
- [Web Flow Analyzer](https://www.evinced.com/): AI web application accessibility testing
- [Mobile Flow Analyzer](https://www.evinced.com/): AI mobile app accessibility testing
- [Site Scanner](https://www.evinced.com/): full-site accessibility scanning
- [Design Assistant](https://www.evinced.com/): accessibility-focused design tooling
- [Unit Tester](https://www.evinced.com/): code-level accessibility testing

## MCP Servers
- [Web MCP Server](https://developer.evinced.com/mcp-servers/web-mcp-server): `@evinced/mcp-server-web`, stdio, tool `evinced_analyze_webpage`
- [Mobile MCP Server](https://developer.evinced.com/mcp-servers/mobile-mcp-server): `@evinced/mcp-server-mobile`, stdio, tools `evinced_accessibility_analyze`, `evinced_get_remediation_instructions`

## SDKs
- Web: Selenium (Java/JS/C#), Cypress, Playwright (Java/JS), WebdriverIO, TestCafe
- Mobile: Appium (Java/Python), Espresso/UIAutomator, XCUITest, WebdriverIO Mobile, Android Mobile Kit
- Distributed via Evinced Artifactory; documented at https://developer.evinced.com/
